# Code Package: C. elegans Microbiome Manuscript

This folder contains the exact scripts used to generate the figures and tables. 
Scripts are named to match the specific Figure/Table and its title in the manuscript.

## Folders:
- `01_Methods_and_Preprocessing`: Core data processing and statistical algorithms.
- `02_Main_Figures`: Scripts generating Figure 1 through Figure 6.
- `03_Supplementary_Figures`: Scripts generating Supplementary Figures 1 through 6.
- `04_Tables`: Scripts generating Main Tables and Supplementary Tables.

## Dependencies
* R (4.5): `DADA2`, `phyloseq`, `vegan`, `DESeq2`, `microbiome`
* Python (3.10+): `pandas`, `numpy`, `scipy`, `matplotlib`, `seaborn`, `scikit-learn`, `Pillow`
